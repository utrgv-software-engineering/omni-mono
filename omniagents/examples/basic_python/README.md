# Basic Python Example

This example shows how to create an OmniAgents app directly in Python with custom tools.

## Files

- `agent.py` – builds the agent and runs the app.
- `tools.py` – simple tools used by the agent.

## Usage

```bash
python agent.py                  # web interface (default)
python agent.py --mode server    # JSON‑RPC server
python agent.py --mode ink       # terminal interface
```
